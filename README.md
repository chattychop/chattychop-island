# chattychop-island
A Dynamic Island for Windows — a floating AI overlay that lives at the top of your screen. Chat with your AI, run quick commands, track tasks, and more, without ever opening a window.
Built by G. Badrinath (Chattychop) · Hyderabad, India

Chat with your own AI, right from the pill

Tools: lock PC, mute, empty recycle bin, screenshot, organize downloads, and more
Rules: your own hotkeys and typed-phrase automations
Clipboard history
Now playing, pulled straight from Windows' media session
Find any file by description
Web research
Sign in with Google — your chats, tasks and notes stay private to your account only
Launch automatically when your PC starts (toggle in Settings)

Setup

Download this repo and unzip it anywhere
Double-click RUN_ISLAND.bat

That's it. The first run sets your computer up automatically (installs Node if you don't have it, grabs what Island needs) — takes about a minute. Every run after that opens straight away.
Keep main.js, package.json, package-lock.json, and RUN_ISLAND.bat together in the same folder. Splitting them up is the most common cause of a "package.json not found" error.

A few things not to do

Don't move the files apart from each other
Don't close the window during first-time setup
Don't panic at the Windows SmartScreen warning — that's Windows flagging an unsigned app, not a virus warning. Click "More info" → "Run anyway."
Don't hand-edit the JSON data files while Island is running
Don't share your admin link or JSONBin key with anyone
