What's actually happening, for the curious 🔧

Island is built on Node.js — if you don't have it, RUN_ISLAND.bat installs it automatically in the background (no separate download needed on most Windows machines). It then runs npm install once to grab Island's pieces, and npm start to open it. You'll never need to type any of this yourself — it's all inside the one file you double-click.
