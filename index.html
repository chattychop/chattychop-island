What's actually happening, for the curious 🔧

Island is built on Node.js — if you don't have it, RUN_ISLAND.bat installs it automatically in the background (no separate download needed on most Windows machines). It then runs npm install once to grab Island's pieces, and npm start to open it. You'll never need to type any of this yourself — it's all inside the one file you double-click.

A few things not to do
🚫
Don't move files out of the foldermain.js, package.json and RUN_ISLAND.bat all need to stay together, in the same folder. Splitting them up is the #1 cause of "package.json not found" errors.
🚫
Don't close the window during first setupThe very first run installs a couple of things automatically — closing it mid-way can leave things half-installed. Just let it finish once.
🚫
Don't panic at the Windows SmartScreen warningWindows flags any app that isn't paid-signed yet, even safe ones — that's not a virus warning, it's a "this developer hasn't paid Microsoft" warning. Click "More info" → "Run anyway."
🚫
Don't hand-edit the JSON files while Island is runningisland_data.json and similar files get read/written live — editing them by hand while the app's open can get overwritten or cause weird state.
🚫
Don't share your admin link or JSONBin keyWhoever has that can edit pricing, codes and everyone's account data. Keep it to yourself only.
